# Kharcha — Warm Professional Finance

## Design Principles
- **Formality and Calm**: Clean layout, strict whitespace, high-contrast readability, 1px borders instead of shadows.
- **Precision**: Tabular figures, Indian rupee currency and grouping (₹1,20,000).
- **No Clutter**: No emojis, no gradients, no dark mode, no decorative illustrations.

## Colors
- Page background: #FFFFFF
- Section and sidebar background: #F7F8FA
- Hover background: #F2F4F7
- Border default: #E4E7EC
- Border strong: #D0D5DD
- Text primary: #101828
- Text secondary: #475467
- Text muted: #667085
- Accent: #1F4E79
- Accent hover: #173B5C
- Accent soft background: #E9F0F7
- Positive: text #067647 on background #ECFDF3
- Warning: text #B54708 on background #FFFAEB
- Danger: text #B42318 on background #FEF3F2

## Typography
- Font Family: Inter, sans-serif
- Display: 32px / 40px, weight 600
- H1: 24px / 32px, weight 600
- H2: 18px / 28px, weight 600
- Body: 15px / 24px, weight 400
- Body strong: 15px / 24px, weight 500
- Small: 13px / 20px, weight 400
- Caption: 12px / 16px, weight 500

## Components
- Cards: 12px corner radius, white, 1px #E4E7EC border, 24px padding, NO shadows.
- Buttons & Inputs: 8px corner radius, 40px height.
